# 🤖 Robot Path Finder

> A visual pathfinding tool made for the **2024 Scioly Robot Tour** competition.  
> My first serious build — and it still slaps.

![screenshot](https://raw.githubusercontent.com/Zynk-dot/robotTour/refs/heads/main/robotTour.png)

---

### 🔍 What It Does

- Build a robot map interactively on the web
- Set **Start**, **End**, **Obstacle Zones**, **Gate Zones**, and the **Last Gate Zone**
- Automatically calculates the **optimal route** through **all gates**
- Highlights the path + shows movement steps and turn count
- Built with pure JavaScript, HTML, and CSS — no frameworks

---

### 🎯 Features

- ✅ Grid-based visual editor
- ✅ A* algorithm with turn minimization
- ✅ Supports obstacle walls between cells (border-line logic)
- ✅ Calculates **all gate zone permutations** to find the best route
- ✅ Console + step tracker (so you know what’s happening)
- ✅ Styled UI with clear controls for each mode
